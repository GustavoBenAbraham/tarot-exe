# Changelog

## 0.2.0 — 20/10/2026

- Interface desktop em colunas com identidade Windows 95/98 e paleta vintage.
- Baralho de 78 cartas com imagens locais, inversões e ampliação.
- Catálogo autoral de interpretações, temas e práticas de reflexão.
- Aprofundamento opcional com Ollama, parâmetros, timeout e cancelamento.
- Histórico UTF-8, exportação, cópia e ajustes de leitura.
- Preferências de janela, ícone próprio e logs rotativos.
- Instalador Windows x64 e versão portátil com runtime Java incluído.
- 53 testes locais, teste de IA real e validações de instalação/desinstalação.

Esta é a primeira versão publicada neste repositório. A evolução anterior
partiu de um MVP com JavaFX, sorteio e interpretação por regras.
